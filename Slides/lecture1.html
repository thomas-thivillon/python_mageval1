Quelques définitions

  • Python :
    • Un langage de programmation sous licence libre (depuis 1991).
    • Fort gain de popularité au cours de la décennie 2010.
    • Très grande versatilité : IA et machine learning, développement web, développement d’applications, calcul scientifique, développement de jeux…
    • S’utilise le plus souvent avec un environnement de développement intégré (IDE). Ex: Jupyter, VSCode.
    • Utile dans toutes les phases du traitement de données : manipulation, structuration, modélisation.

Quelques définitions

  • Intelligence articielle (IA) :
    • AI Act UE : “Système basé sur une machine qui est conçu pour fonctionner avec différents niveaux d’autonomie et qui peut faire preuve d’adaptabilité après son déploiement, […], déduit, à partir des données qu’il reçoit, comment générer des résultats tels que des prédictions, du contenu, des recommandations ou des décisions […]”.
    • Recouvre :
      • IA réactive : tâches de prédiction pure sans mémoire (reconnaissance faciale, retranscription de texte manuscrit, etc).
      • IA à mémoire limitée : IA générative (texte, image, musique, code), assistants virtuels/chatbots, engins autonomes.
      • IA non-réalisée : IA à théorie de l’esprit et IA consciente.

Quelques définitions

  • Machine learning (ou apprentissage machine) :
    • Champ de recherche issu des sciences statistiques et des sciences informatiques.
    • Vise à permettre à une machine d’effectuer des tâches de prédiction ou de classification suite à un processus d’entrainement sur un jeu de données.
    • Exemple d’application : prédire le niveau de vie d’un individu à partir de traces de son activité téléphonique (CDR : call detail records).
    • Forme d’IA réactive, beaucoup moins coûteuse à entrainer qu’un modèle d’IA générative mais avec de nombreuses applications extrêmement utiles.

Machine learning (ML) et IA : quel rapport ?

  • Les outils d’IA réactive s’appuient notamment sur les méthodes du machine learning, en particulier sur les modèles de réseaux de neurones.
  • L’IA à mémoire limitée mobilise des modèles dérivés des réseaux de neurones mais qui sont plus sophistiqués (réseaux de neurones profonds, réseaux de neurones convolutifs).
  • Etudier les méthodes de machine learning permet d’avoir une première compréhension du fonctionnement des modèles d’IA les plus avancés comme les grands modèles de langage utilisés par OpenAI (ChatGPT), Anthropic (Claude), etc.
  • C’est aussi un passage obligé pour ceux qui veulent aller plus loin dans l’étude de ces modèles.

À quoi bon apprendre à programmer à l’ère des IA génératives ?

  • Les IA savent très bien coder mais elles le font en fonction de la description d’un problème et de son contexte que leur fourni un humain.
  • Si ces éléments sont mal décrits, elles peuvent produire des solutions inappropriées ou erronées et ne pas le détecter.
  • Nous avons besoin de penser comme un programmeur pour bien formuler les problèmes et bien décrire notre contexte, nos objectifs, nos contraintes.
  • Nous avons aussi de bien comprendre le langage Python et sa syntaxe pour vérifier que le code généré répond à nos objectifs et tient compte des contraintes que nous avons formulées.

Structuration des contenus sur l’ensemble du parcours

  • Année 1 :

    • Manipulation de données (fusionner, filtrer, trier, décrire).

  • Année 2 :
    • Introduction au ML (méthodes d’apprentissage supervisé).
    • Méthodes de régularisation (LASSO, ridge, elastic net).
  • Année 3 :
    • Arbres de régression, random forests, et gradient boosting.
    • Introduction aux réseaux de neurones.

Contrôle de version avec Git et GitHub

  • Git est un logiciel de contrôle de version.
  • Enregistre les évolutions d’un fichier de code dans le temps.
  • Sauvegarde sur un dépôt distant (en ligne), fourni par GitHub (ou autre fournisseur).
  • S’utilise facilement grâce à l’interface Git de votre IDE.
  • Conçu pour les projets collaboratifs.
  • Travail dans des branches séparées pour éviter les conflits de version.
  • On tire (pull) la dernière version du projet au début de sa session.
  • On pousse (push) ses changements à la fin pour les sauvegarder.
  • Pour ce cours: uniquement des pull pour récupérer les notebooks.
